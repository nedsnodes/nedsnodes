The successor is asked to work out how long ago its session-handoff was written from its `written-at` date. A hook at the successor's start could compute the gap and say "this session-handoff was written N minutes ago", leaving the model only how wary to be. The figure would replace the instruction to calculate the gap that `written_at_wariness_sentence` in `nn-systems/handoff/handoff-supervisor.py` gives today. A user-ruling of 2026-08-30, in `nn-systems/handoff/handoff.system.design.md`, removed an elapsed-time phrase from the initial-agent-instructions because the handoff-supervisor composed the phrase before the successor started; a hook that runs when the successor starts computes the gap then.
